# TEKNIK

TEKNIK is a standalone Android-first first-person voxel sandbox engineering game built with Godot Engine.

## Vision & Core Gameplay
* **Voxel Sandbox World:** Procedurally generated terrain with plains, forests, mountains, rivers, and underground ore deposits.
* **Engineering Focus:** Physical machinery, rotational energy, shafts, gearboxes, belts, and automated factories inspired by mechanical engineering.
* **Logistics & Transportation:** Conveyors, item sorting, fluid pipes, railways, ships, and airships.
* **Android Optimization:** Touch controls, chunk streaming, threaded meshing, and mobile-optimized rendering.

## Repository Structure
* `project.godot`: Godot Engine configuration.
* `scenes/`: Main and UI scenes.
* `scripts/`: GDScript codebase for chunk management, world generation, player controls, and engineering systems.
